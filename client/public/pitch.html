ORBITAL-01 · Simulated telemetry

Mission Control AI

An agent that helps an operator understand a spacecraft anomaly, not just see that one exists.

The problem

An alert is not an explanation.

Too many channels

Temperature, pressure, power, and vibration move at the same time. The operator has to decide which one matters.

Too little context

A red number says the limit was crossed. It does not say what else stayed normal, or what to check next.

What the agent does

DETECTOR

Finds the breach

  • Reads simulated telemetry every second
  • Compares each channel with a fixed limit
  • Raises WARNING, then CRITICAL
  • Does not ask the model if something is wrong
INVESTIGATOR

Explains the breach

  • Receives the alarm plus the recent channels
  • Separates what was observed from what might be the cause
  • Ranks causes with a confidence
  • Recommends checks for a human to review

Live demonstration

Three clicks.

  1. 01 Normal Operation. Every channel is inside limits.
  2. 02 Engine Overheating. Temperature crosses 550 K, then 600 K.
  3. 03 The report. Facts, hypotheses, evidence, and actions.

What the operator gets

A report, not a command.

Observed

The value, the limit it crossed, and the channels that stayed quiet.

Hypotheses

Possible causes, each with a confidence between 0 and 1. None of them is treated as certain.

Evidence

The numbers the conclusion is allowed to use. The agent does not invent sensors.

Actions

Checks for a person to review. No valve, engine, or shutdown command is sent.
